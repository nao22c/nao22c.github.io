Note Dentaku

A new kind of calculator that saves results directly as notes

計算結果をそのままメモに残せる、新しいタイプの電卓アプリ

Download on theApp Store App Store からダウンロード

Features

主な機能

Save Results to Notes
計算結果をメモに保存
Transfer calculation results to the note area with one tap. Review your work anytime.
ワンタップで計算結果をメモ欄に転記。あとからいつでも見返せます。
Text Editing
テキスト編集
Freely add text in the note area — annotate what each calculation was for.
メモ欄に自由にテキストを追加。それぞれの計算が何のためのものか書き添えられます。
Categories
カテゴリ分け
Organize saved notes by category so you can find them quickly when needed.
保存したメモをカテゴリごとに整理。必要なときにすぐ見つけられます。
Simple Design
シンプルなデザイン
An intuitive, clutter-free interface focused on what matters.
直感的で無駄のないインターフェースで、必要な操作に集中できます。
