よくある質問

履歴のパネルが出てきません

初期設定のショートカットは ⌘⇧V です。他のアプリが同じキーを使っていると登録できないことがあります。設定画面でショートカットをクリックし、別のキーに変更してみてください。メニューバー右上のアイコンをクリックしても同じパネルが開きます。

コピーしたのに履歴に残りません

パスワードマネージャーなど、一部のアプリは「クリップボード管理アプリに記録させない」という指定をしてコピーします。Stack はこの指定を尊重するため、意図的に保存しません。また、設定した上限を超える画像も保存されません。

Mac 間で同期されません

両方の Mac が同じ Apple ID でサインインし、システム設定の iCloud で iCloud Drive が有効になっているかご確認ください。初回の同期には数十秒かかることがあります。

削除した項目を戻したい

削除した項目はゴミ箱に移動します。ウィンドウ左のサイドバーからゴミ箱を開き、項目を選んで「戻す」を実行してください。保持期間は設定画面で変更できます。

大事な項目が自動で消えないようにしたい

項目を選んでロックすると、履歴の上限に達しても、すべて削除を実行しても消えません。フォルダに入れた項目やタグを付けた項目も自動削除の対象外になります。

履歴をバックアップしたい

ファイルメニューの「履歴を書き出す…」（⌘⇧E）で、テキストと画像をフォルダに書き出せます。お試し期間の終了後もご利用いただけます。

購入したのに反映されません

設定画面の「購入を復元」をお試しください。購入時と同じ Apple ID でサインインしている必要があります。

FAQ

The panel does not appear

The default shortcut is ⌘⇧V. If another app already uses it, the shortcut cannot be registered — open Settings and record a different one. Clicking the menu bar icon opens the same panel.

Something I copied was not saved

Password managers mark their content as private, and Stack deliberately honours that marker. Images larger than the limit set in Settings are also skipped.

My Macs are not syncing

Make sure both Macs are signed in to the same Apple ID and that iCloud Drive is enabled in System Settings. The first sync can take a minute.

I deleted something by mistake

Deleted entries go to the Trash in the sidebar. Select one and choose Put Back. How long they stay there is configurable in Settings.

Keeping important entries forever

Lock an entry and it survives the history limit and Delete All. Entries filed into a folder or given a tag are also exempt from automatic clean up.

Backing up the history

Use File → Export History (⌘⇧E) to write the text and images into a folder. This keeps working after the trial ends.

My purchase is not recognised

Use Restore Purchases in Settings, signed in with the Apple ID you bought with.
